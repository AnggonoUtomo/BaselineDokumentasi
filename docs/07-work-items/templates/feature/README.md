# Feature Package

Use this package for `feature` work. Copy the entire directory into the matching work-item collection and replace all placeholders.

## Required sequence

1. `01-FEATURE-SPEC.md` — Problem, users, scope, requirements, business rules, acceptance criteria, non-goals and dependencies.
2. `02-TECHNICAL-DESIGN.md` — Current state, proposed design, module/data/API/event/security changes, alternatives and risks.
3. `03-IMPLEMENTATION-PLAN.md` — Ordered vertical slices, dependencies, allowed changes, rollout and rollback.
4. `04-TEST-PLAN.md` — Unit, integration, contract, feature, security, edge-case and regression tests.
5. `05-REVIEW-REPORT.md` — Correctness, architecture, readability, security, performance and unresolved findings.
6. `06-COMPLETION-REPORT.md` — Delivered scope, deviations, evidence, baseline sync and follow-up work.

Also add `CONTEXT-PACK.md`, `DEVIATION-RECORD.md` when needed, and `EVIDENCE-MANIFEST.md` before completion.
