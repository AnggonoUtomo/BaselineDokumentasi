# Integration Package

Use this package for `integration` work. Copy the entire directory into the matching work-item collection and replace all placeholders.

## Required sequence

1. `01-INTEGRATION-BRIEF.md` — Provider, use cases, ownership, environments, data classification, cost and constraints.
2. `02-CONTRACT-SPEC.md` — Endpoints/messages, auth, schemas, versioning, idempotency and compatibility.
3. `03-FAILURE-MODES.md` — Timeout, retry, rate limit, partial failure, duplicate, ordering, fallback and circuit breaking.
4. `04-SECURITY-ASSESSMENT.md` — Secrets, trust boundaries, webhook validation, privacy, threat scenarios and controls.
5. `05-IMPLEMENTATION-PLAN.md` — Adapter boundary, sandbox, observability, rollout and rollback.
6. `06-SANDBOX-TEST-REPORT.md` — Test cases, provider responses, error paths, rate limits and evidence.
7. `07-PRODUCTION-READINESS.md` — Credentials, limits, alerts, runbook, support contacts, cost, rollback and approval.

Also add `CONTEXT-PACK.md`, `DEVIATION-RECORD.md` when needed, and `EVIDENCE-MANIFEST.md` before completion.
