# ID Conventions

| Prefix | Meaning | Example |
|---|---|---|
| `REQ` | Requirement | `REQ-ACL-001` |
| `BR` | Business rule | `BR-FIN-002` |
| `BC` | Boundary | `BC-ACL-001` |
| `MOD` | Module | `MOD-ACL-AUT` |
| `FTR` | Feature | `FTR-ACL-003` |
| `BUG` | Bug | `BUG-ACL-014` |
| `REF` | Refactor | `REF-CORE-004` |
| `INT` | Integration | `INT-PAY-001` |
| `MIG` | Data migration | `MIG-STD-002` |
| `UPG` | Dependency upgrade | `UPG-PHP-003` |
| `SEC` | Security change/review | `SEC-ACL-005` |
| `PERF` | Performance work | `PERF-API-002` |
| `DEP` | Deprecation/removal | `DEP-API-001` |
| `INC` | Incident | `INC-PROD-007` |
| `ARC` | Architecture change | `ARC-ACL-001` |
| `ADR` | Architecture decision | `ADR-0012` |
| `CTR` | Boundary/API contract | `CTR-ACL-004` |
| `EVT` | Event | `EVT-ACL-009` |
| `TSK` | Task | `TSK-ACL-001-02` |
| `TST` | Test case | `TST-ACL-020` |
| `DEV` | Deviation | `DEV-ACL-003` |
| `DOC-PROP` | Documentation proposal | `DOC-PROP-002` |
| `BL` | Baseline snapshot | `BL-2026-001` |

IDs are stable and never reused. Human-readable names may change; IDs do not.
